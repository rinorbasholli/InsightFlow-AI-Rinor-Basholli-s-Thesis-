\chapter{Requirements and use cases}
\label{cha:req}

This chapter lists the requirements I used while I implemented the laboratory. I wrote them after the first interface draft and after the meeting with my supervisor. I needed a list that I could test against the code, not a generic product backlog.

\section{Actors}
\label{sec:actors}

I considered three actors.

\begin{description}
\item[Student / author] I use the laboratory to generate samples, load the 90-row set, and run the local evaluation scripts.
\item[Examiner] An examiner opens the laboratory, logs in, and walks through the four screens.
\item[Supervisor] The supervisor reviews the same screens and asks where each number comes from.
\end{description}

\section{Use cases}
\label{sec:uc}

I used the following use cases when I tested the interface by hand.

\subsection{UC1 --- Log in to the laboratory}
The examiner opens \texttt{http://localhost:3000} (or a host that I start from this repository). The React login form posts to \texttt{/api/login} and stores an HttpOnly cookie. HTTP Basic Auth still works for \texttt{curl} and for older clients. After a valid pair, later \texttt{/api/*} calls require that cookie or the Basic header. Static files load so the login page can render. If \texttt{LAB\_BASIC\_USER} or \texttt{LAB\_BASIC\_PASS} is missing in production, the server answers 503 and the laboratory stays closed.

\subsection{UC2 --- Load the 90-sample teaching set}
On the dashboard the examiner clicks ``Reset \& Load Study Dataset (90 Samples)''. \texttt{App.tsx} calls \texttt{generate90Samples()} and stores the array in React state. The counts 30 / 30 / 30 appear. The mean designed realism and the ``100 minus mean AI detectability'' values appear. Those two percentages are configuration from the bands in \texttt{academicDataset.ts}. They are not Gmail results.

\subsection{UC3 --- Generate an AI phishing email}
On the AI Phishing Lab tab the examiner sets a scenario and clicks generate. The browser posts to \texttt{/api/generate-phishing}. If the custom prompt looks injected, the server returns 400. If the hourly limit is reached, it returns 429. Otherwise Gemini is called. On success the JSON has \texttt{source: "gemini"}. On API error the JSON has \texttt{source: "fallback"} and a fixed ESTiG-themed template.

\subsection{UC4 --- Analyse pasted text or a local file}
The examiner pastes subject and body, or loads a \texttt{.txt} / \texttt{.eml} file. The browser posts to \texttt{/api/analyze-email}. Known samples keep their teaching label. Live text gets a Gemini class or the keyword fallback. The dashboard then shows the new row with \texttt{analysisSource}.

\subsection{UC5 --- Inspect a deepfake scenario}
The examiner picks one of the three presets or types another filename. The server never opens the file. An exact preset name returns \texttt{source: "preset"}. Another name goes to Gemini or to \texttt{getDynamicFallbackDeepfake}. Marker confidences are simulated.

\subsection{UC6 --- Run a real model attack}
On the AI Model Attacks tab the examiner chooses a CIFAR-10 class pair, FGSM or PGD, and an $\varepsilon$ value and clicks simulate. Express posts to the Python service. The default attack is untargeted FGSM or PGD on CIFAR-10 ResNet-56, with $L_\infty$ clipped to $\varepsilon$. Targeted mode is only used when the request sets \texttt{targeted: true}. A success answer has \texttt{source: "computed"} and softmax values from that network. If the service is down, the UI shows an error. Gemini is not used. There is no ResNet-50 control.

\subsection{UC7 --- Check the attack service}
The front end or a script can call \texttt{GET /api/eval/health}. Express forwards to the Python \texttt{/health} route. This is how I know whether UC6 can succeed.

\section{Out of scope}
\label{sec:oos}

I did not implement a mail sender. I did not implement a real deepfake detector. I did not harvest inboxes. I did not train a production spam filter. I did not keep server-side logs of generated emails. Those limits are intentional. They also appear again in Chapter~\ref{cha:disc}.
