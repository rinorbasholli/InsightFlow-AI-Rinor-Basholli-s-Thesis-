\prefacesection{Resumo/Abstract}
Este relatório descreve o laboratório educacional InsightFlow AI (AI Cybersecurity Risk Lab), que implementei para o Projecto de Licenciatura em Engenharia Informática. O laboratório junta, num só fluxo, três riscos de cibersegurança ligados à inteligência artificial: correio de phishing gerado por modelos de linguagem, cenários de deepfake e ataques adversariais a um classificador de imagens. O conjunto de 90 emails é um conjunto de templates em memória, com semente fixa 20260927. O separador de deepfake não inspecciona bytes. A avaliação adversarial usa uma ResNet-56 pré-treinada em CIFAR-10. Cada resposta JSON de análise tem um campo \texttt{source} (\texttt{gemini}, \texttt{fallback}, \texttt{preset} ou \texttt{computed}). Os valores 75\% e 51\% do painel são configuração das bandas do dataset, não resultados. No corpus de wording, o F1 sem o campo From é 0,706; com o remetente é 0,756 (divisão 70/30). A linha de base ``sempre phishing'' é 0,733. São valores de ensino, não um detector de mailbox.

This report describes the educational laboratory InsightFlow AI (AI Cybersecurity Risk Lab) that I implemented for the Informatics Engineering project course. The laboratory puts three AI-related cybersecurity risks in one workflow: language-model phishing mail, deepfake scenarios, and adversarial attacks on an image classifier. The 90-email set is an in-memory template set with fixed seed 20260927. The deepfake tab does not inspect bytes. The adversarial evaluation uses a CIFAR-10 pretrained ResNet-56. Each analytical JSON response has a \texttt{source} field (\texttt{gemini}, \texttt{fallback}, \texttt{preset}, or \texttt{computed}). The dashboard values 75\% and 51\% are configuration from the dataset bands, not findings. On the reconstructed wording corpus, F1 is 0.706 without the From line and 0.756 with it (70/30 split), against an always-phish baseline of 0.733. That is a computed score on teaching labels, not a mailbox detector finding.

\prefacesection{Abstract/Resumo}
This report presents InsightFlow AI, an educational web laboratory for three AI cybersecurity risks: AI-generated phishing, deepfake media scenarios, and adversarial examples. I built a React and Express application with HTTP Basic Auth, rate limits, prompt-injection checks, and a Python evaluation service for FGSM and PGD. I cite only numbers that exist in exported files. The 200-image adversarial export has clean accuracy $0.955$ on CIFAR-10 ResNet-56.

Este relatório apresenta o InsightFlow AI, um laboratório web educacional para três riscos de cibersegurança da IA: phishing gerado por IA, cenários de deepfake e exemplos adversariais. Implementei uma aplicação React e Express com autenticação Basic, limites de taxa, verificação de injecção de prompts e um serviço Python para FGSM e PGD. Cito apenas números que existem em ficheiros exportados. A exportação adversarial de 200 imagens tem exactidão limpa $0{,}955$ na ResNet-56 CIFAR-10.
